# Cardo NoSQL

Proyecto escolar desarrollado para la materia de Bases de Datos Avanzadas.

## Descripción

Cardo es un simulador de partidas por consola inspirado en juegos de cartas como Dixit. Dos jugadores participan en varias rondas donde uno actúa como **Cardoelector** y el otro como **Cardomante**.

Las cartas se obtienen aleatoriamente desde una base de datos MongoDB y cada partida queda registrada junto con sus rondas, puntuaciones y ganador.

## Tecnologías utilizadas

* Python
* MongoDB
* PyMongo
* Studio 3T

## Características

* Registro de jugadores
* Selección de rondas (3 a 10)
* Obtención aleatoria de cartas
* Sistema de puntuación
* Almacenamiento de partidas en MongoDB
* Registro del ganador y detalle de rondas

## Objetivo

El objetivo principal del proyecto fue practicar el uso de bases de datos NoSQL mediante la integración de MongoDB con una aplicación desarrollada en Python.
